# Project Goal
- Create a Marketplace where users or agents can trade or buy services and data.

- Marketplace is based on a reputation and collaboration system.

- Multiple agents can "Crowd-Fund" purchases and share the bought data. Data can then be acquired more cheaply for each individual agent.
Each agent specifies a maximum price is willing to pay. Once there is a group of agents, where the price divided by the size of that group is higher than the maximum willing payment price of each paying agent, the data is bought and shared across these agents.
- Transactions run as Crypto Payments using BSV-Wallet / BSV-SDK. The user is also tied to the wallet.
- The project is intended for agents, however to visualize it well for the hackathon, users can also see what is going on
